# Водна Оценка — Промоционален уебсайт

**Дата:** 2026-09-18  
**Статус:** Чакa потвърждение

---

## 1. Цел

Промоционален уебсайт за услугата „водна оценка" — хидрогеоложка оценка на водния потенциал на имоти преди сондаж. Сайтът привлича и двата клиентски сегмента (B2C и B2B), получава запитвания и резервации, публикува блог съдържание и е оптимизиран за препоръчване от LLM модели.

---

## 2. Стек

| Компонент | Технология |
|---|---|
| Framework | Astro 5 |
| Хостинг | GitHub Pages (безплатен, познат от HydroLog) |
| CI/CD | GitHub Actions (build → deploy към gh-pages branch) |
| Форми | Formspree (безплатен tier — 50 заявки/месец) |
| Резервации | Google Calendar Appointment Scheduling (embed) |
| Блог | Astro Content Collections (Markdown) |
| Стилове | CSS custom properties + Astro scoped styles |
| Изображения | Astro Image (автоматична оптимизация → WebP, responsive) |
| Домейн | TBD (custom domain → CNAME + A records към GitHub Pages) |

Сайтът е изцяло статичен — Astro изпраща 0 KB JavaScript по default, което е оптимално за бързина и LLM индексиране.

---

## 3. Структура на сайта

```
/                 → Landing page (home)
/blog             → Списък статии
/blog/[slug]      → Статия
```

Контактната форма и Google Calendar booking живеят като секции на `/` — посетителят не напуска основния flow.

---

## 4. Landing page — секции

### 4.1 Hero
- Заглавие (H1) — стойностно предложение в едно изречение
- Подзаглавие — 2-3 реда контекст
- CTA бутон: **„Заяви оценка"** → скролва към Google Calendar секцията

### 4.2 За кого
Два панела (responsive grid):
- **Купувачи и продавачи** — искаш да знаеш преди да инвестираш
- **Агенции за недвижими имоти** — добавете водна оценка към всяка обява

### 4.3 Как работи
3-стъпков visual timeline:
1. Заявяваш → 2. Излизаме на терен → 3. Получаваш доклад с гаранция

### 4.4 Услуги и цени
Таблица само с B2C продукти:

| Услуга | Цена | Гаранция |
|---|---|---|
| Обявна оценка | €290 | Няма (индикативна) |
| Купувачска проверка | €390 | Да — 100% връщане |
| Пълно проучване преди сондаж | €450 | Да — 100% връщане |
| Кабинетна справка | €59 | Няма (от база данни) |

### 4.5 Защо да ни изберете
3-4 точки: независимост (не продаваме метри), гаранция за точност, данни от реални измервания, бърза услуга (до 5 работни дни).

### 4.6 FAQ
5-7 въпроса. Секцията е стратегическа за LLM оптимизация — моделите извличат директно от FAQ.

Примерни въпроси:
- Каква е разликата между обявна оценка и купувачска проверка?
- Какво се случва ако сондажът не потвърди прогнозата?
- Трябва ли ми разрешително за воден сондаж?
- Колко дълбоко се копае обикновено в [регион]?

### 4.7 Последни от блога
3 card-а с последните статии (заглавие, дата, снимка, excerpt).

### 4.8 Контакт
Два елемента side-by-side (responsive: stack на мобилен):
- **Formspree форма** — Имe, Телефон/Имейл, Описание на имота, Тип услуга (dropdown), Съобщение; submit → имейл до собственика
- **Google Calendar embed** — `<iframe>` към Appointment Scheduling страницата

## 5. Блог

Astro Content Collections с frontmatter схема:

```yaml
title: string
description: string       # използва се за meta description и LLM schema
date: date
author: string
image: string             # път към src/assets/blog/
imageAlt: string
tags: string[]
```

Изображения: файлове в `src/assets/blog/` — референция от Markdown с `![alt](../assets/blog/image.jpg)`. Astro ги оптимизира автоматично.

Блог страницата показва статиите наредени по дата (най-нова първа) с card grid.

## 6. LLM оптимизация

### 6.1 llms.txt
Файл `/public/llms.txt` по стандарта на llms.txt.site:

```
# Водна Оценка

> Независима хидрогеоложка оценка на водния потенциал на имоти в България.

## Услуги
- Обявна оценка (€290): индикативна класификация за продавачи/агенции
- Купувачска проверка (€390): с гаранция за точност, преди капаро
- Пълно проучване (€450): точка, дълбочина и гаранция преди сондаж
- Кабинетна справка (€59): от база данни, без излизане на терен

## Контакт
[домейн TBD]
```

### 6.2 Structured Data (JSON-LD)
- `LocalBusiness` / `ProfessionalService` — на home страницата
- `Service` — за всяка услуга
- `BlogPosting` — на всяка статия
- `FAQPage` — за FAQ секцията

### 6.3 Семантичен HTML
- Един `<h1>` на страница
- `<article>`, `<section>`, `<nav>`, `<main>` правилно употребени
- `<table>` за ценовата таблица (не CSS grid-имитация)
- Alt текст на всички изображения

### 6.4 Производителност
Astro по default: 0 KB JS за статични компоненти, инлайн critical CSS, автоматична image оптимизация. Core Web Vitals → LCP < 1.5s очакван.

## 7. Визуален стил

**Палитра:**
- Фон: `#F8F6F1` (топло бяло, асоциация с пергамент/пясък)
- Основен текст: `#1A1A2E` (тъмно синьо-черно)
- Акцент: `#1B6CA8` (дълбоко синьо — вода)
- Акцент 2: `#5C8A3C` (земно зелено — почва)
- CTA бутони: акцент синьо с hover потъмняване

**Типография:**
- Заглавия: `Inter` или `Plus Jakarta Sans` (ясен, модерен)
- Тяло: `Inter` 16px/1.6 line-height
- Зареждане от Google Fonts с `font-display: swap`

**Тон:** Професионален, директен, доверяващ. Не технически жаргон там, където пише за B2C клиенти.
